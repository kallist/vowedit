## Dependency audit

The base lockfile already contained transitive `source-map-js@1.2.1`. Advisory
[GHSA-68fv-2mgg-jv7q](https://github.com/advisories/GHSA-68fv-2mgg-jv7q) is high severity, indexed source-map section offset CPU/DoS; affected versions `>=1.0.0 <1.2.2`.
Paths include Next → PostCSS → source-map-js and Vitest → Vite → PostCSS → source-map-js.
The initial scan reported six high entries through those dependent packages, not six newly added vulnerabilities.
Only the compatible transitive patch `source-map-js@1.2.2` changed in the lockfile. No framework major or manifest dependency changed. The resulting audit reports zero vulnerabilities; build/unit/browser gates validate the resolved dependency.

## Limits

- Real RunningHub strategy semantics: NOT TESTED. Real ComfyUI: NOT TESTED. Existing V0.1 evidence is historical and does not validate these strategies.
- Fixed English strategy directives are visible and may be appended to Chinese base text. UI locale does not translate prompts. Transport forwards text; this is not proof of remote model input/semantic suitability.
- Docker: N/A (no Docker architecture). Multi-process/distributed workers and cloud auth: NOT IMPLEMENTED; existing single-worker local trust boundary remains.
- Starters scan run JSON under SQLite transactions; adequate for the current local prototype, not a claim of large-scale indexed performance. Failed/racing filesystem writes may leave unreferenced files; automatic deletion/GC is NOT IMPLEMENTED.
- No complete unsent painting autosave. Latest 50 history entries are a display limit; parent ID lookup remains available.
- V0.2.1 Extension / V0.3 Agent: NOT IMPLEMENTED. No paid provider call, cloud upload, merge, release or deployment in this delivery.

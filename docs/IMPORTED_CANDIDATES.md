# Imported candidates — V0.1 bounded addition

Generation and import are separate application commands. `CreateRun` still invokes the configured
`ImageEditProvider`. `CreateImportedRun` accepts already-uploaded candidate assets and enters the
same worker at evaluation. No fake ImportedImageProvider, external SDK, new dependencies or migration.
Evaluation, ranking, thresholds, weights, minimum change, metric version and Ghost formula unchanged.

## API and state

`POST /api/assets?kind=candidate` reuses the original PNG/JPEG upload boundary: MIME/extension agreement,
10 MB body limit, safe still-image decode, 32–1536 sides, EXIF orientation, metadata stripping, UUID
local PNG storage. No browser filenames become storage paths; assets remain outside the public tree.

`POST /api/imported-runs` (202):

```json
{
  "source_image": "original-asset-uuid",
  "contract": {"change": {"instruction": "Recolor jacket navy", "mask": "change-mask-uuid"},
    "keep": [{"type": "manual_region", "label": "Face", "mask": "keep-mask-uuid", "threshold": 98}],
    "background_threshold": 98},
  "request_key": "request-uuid",
  "candidate_images": ["candidate-a-uuid", "candidate-b-uuid", "candidate-c-uuid"],
  "source_label": "Codex built-in imagegen"
}
```

Exactly three candidates, 1–80 trimmed source-label characters, at least one KEEP rule. Verify all
asset kinds and decode actual candidate dimensions before submission; validate masks with the
existing contract validator. Mismatch returns 400 `CANDIDATE_SIZE_MISMATCH`, with no resize or queued
run. Schema forbids extra fields including URL, filesystem paths and executable/workflow configuration.
The label is descriptive user attribution, not verification of model identity or provider execution.

States: queued → evaluating → completed / partial / failed_evaluation. Provider jobs stay empty,
seed=null, candidate_source=imported. Metadata includes provider=imported, source=external, source_label,
simulation=false. Simulation=false means no Mock provider execution, not necessarily model inference.
Only evaluation can retry: saved assets and identities are reused. Generation retry returns 409
`GENERATION_NOT_APPLICABLE`. Existing generated paths and their receipts remain compatible.

Receipt v1 adds external-import/source_label/generation_notice and imported=3; generated=0 for imported
runs. UI explicitly labels IMPORTED, skips the generation stage and duration, offers no generation
retry, and allows each inspected imported candidate to receive an independent human review. System
ranking/suggested candidate remain unchanged. The same existing review API persists those verdicts.

## Persistence and concurrency

All candidate references are submitted together with the queued evaluation job in existing SQLite
BEGIN IMMEDIATE / unique request-key / payload-hash transaction. Conflicting reuse returns JOB_CONFLICT;
parallel identical requests yield one run. Images were atomically saved before references are submitted;
a rejected request can leave uploaded assets, as in the existing upload flow. No automatic deletion.
There is no asset mutation/deletion API; trusted local filesystem access remains outside this boundary.
One process/file-lock-protected worker is retained. Interrupted evaluation preserves imported images;
queued imports resume, failed evaluation can retry without reimport or generation. Browser refresh
replays the original payload/key to the import endpoint; older generated submissions remain recoverable.

## Evidence boundaries

Offline fixtures are generated by `scripts/create_import_fixtures.py`; all test reviews are synthetic
test actions. Hosted CI uses those fixtures, never imagegen or a cloud API. Actual external outputs and
their explicit user visual review are separate: [Blue Jacket record](evidence/imported/blue-jacket-gpt-image).
Their original dimensions differ, so real imported evaluation is NOT TESTED. No resize, composite,
post-edit or relaxed threshold was used to obtain a passing case. RunningHub failed evidence is retained.

Local checks, browser/viewport evidence and current hosted CI are recorded in
[delivery validation](IMPORTED_VALIDATION.md). Docker, real ComfyUI and direct OpenAI API: NOT TESTED.

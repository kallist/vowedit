## Read-only audit

- **Authority:** exact loopback Host first; ordinary/null/wrong origin denied; any declared extension
  identity requires bearer authentication with registered metadata and route/method grant. Missing
  Origin is accepted only for a valid bound bearer or browser same-site/same-origin legacy GET.
  Exact preflight performs no command. Revoke responses retain authenticated CORS context.
- **Secret handling:** the code appears only in the approved full UI/manual panel input; the bearer
  enters only the exchange response, trusted extension storage and private headers;
  no automatic page bridge, query secret, host-page DOM, persistent image store, provider-key exposure
  or raw backend token registry. Fixed random-secret decoding/digest plus constant-time comparison.
  Synthetic leak test covers Run/receipt/DB/logs/PNG; error messages do not reflect exceptions.
- **Persistence/concurrency:** one new table, schema-versioned bounded snapshots, fixed source,
  validated reference kinds/dimensions/readability/provenance. Immediate transaction handles key/hash
  replay/CAS, then atomic Run/job/submitted-draft binding. Existing jobs replay first. Controlled
  migration/submit failures roll back; registry write failures retain code/authority correctly.
  SQLite readers inside validation perform no writes; immutable files have no application GC race.
- **Compatibility:** absent optional draft fields are removed from legacy hash payload; worker,
  provider transport, seeds, evaluator and Boundary Lock algorithms remain unchanged. Immutable
  starter API and lineage remain separate from mutable draft API. Desktop uses default same-origin
  adapters; provider types/Chrome APIs do not leak into shared components.
- **Product state:** saved acknowledgment before full escape/preparation/submit; no generation from
  paint/pair/adopt/continue. Recommendation/preview/adoption/human review remain distinct. Export
  reads adopted final pixels, including prepared outputs. Human FAIL remains visible, preservation
  is not quality, locked scores are attributed to composition, and undefined KEEP stays explicit.
- **UI/assets:** shared tokens/catalogs, four narrow widths, wrapped Chinese and focus/keyboard
  controls. Authenticated Blob URLs are stable per ID/recipe, no unauthenticated fallback. Cleanup
  aborts/revokes, reconnect creates a fresh scope, hidden views pause bounded polling.
- **Delivery:** no prior experimental FAIL rewritten, no real user data upgrade, secrets/runtime
  artifacts excluded, Draft PR only, no merge/tag/release/deployment/store operation. Final-SHA CI
  must be observed after the last documentation/evidence commit.

No remaining substantive implementation defect was identified in this pass. The missing native
Chrome acceptance is a remaining BLOCKING delivery gate, not silently waived. Edge, real-provider
semantics, actual OS clipboard paste-back, real-user migration and multi-process deployment remain
NOT TESTED. No full WCAG/pixel-precision or Windows ACL hardening certification is claimed.

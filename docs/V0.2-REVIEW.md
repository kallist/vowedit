## Integrity review

`BEGIN IMMEDIATE` covers read-current selection, CAS and updates. Same desired adoption is a no-op but still checks terminal state/resource validity. Continue hashes operation/parent/candidate/revision/confirmations; durable result lookup precedes current-selection validation. The registering transaction repeats lookup and state validation, preventing concurrent duplicate registrations and TOCTOU selection changes. File-before-reference ordering permits orphans only; insert/update failures roll back both references. Tests inject these boundaries and restart the service against isolated data.

Starter entries do not enter receipts, so Continue does not mutate the parent's canonical evidence. Generated/imported child source must match the server-owned starter; user-supplied arbitrary parent fields are forbidden. Generation retry is explicitly distinct. SQLite WAL, worker ownership and queue limits remain in the existing machinery.

Legacy hash removes only newly introduced defaults, preserving the old shape. Strategy hashes include a frozen plan/version; worker/replay/retry use it. Locale is presentation-only: original intent, notes, numeric values, canonical enums and receipt data are never translated. Provider instructions/templates are visible. Evaluation/ranking/preparation/provider implementations and workflow fingerprints have no code changes.

No actual user database validation/migration; all app-starting validation processes configure isolated roots before import. User planning documents and untracked workflow stay outside the commit.

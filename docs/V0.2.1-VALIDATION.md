## Packaged extension evidence

`e2e-extension/panel.spec.ts` launches bundled Playwright Chromium with a temporary persistent
profile and the built unpacked package, observes its real service worker and actual runtime ID,
then opens `chrome-extension://<runtime-id>/sidepanel.html`. No fake Chrome API supplies the UI.
The test page is **not** the browser toolbar's native Side Panel.

At 360/400/480/520 pixels, pairing requires an explicit full-UI approval and manual test transfer
of its one-time code. The code is hidden and the panel input clears before screenshots. Actual
private extension GET evidence records `Origin: absent`, `Sec-Fetch-Site: absent`, Authorization
present. Unpaired GET without client headers returns 403. Evidence records only header presence,
never the bearer value. The absent-Origin result is bundled Chromium evidence, not actual Chrome QA.

The tests use tall project-owned 640×704 fixtures, source-coordinate pointer dabs (480,352) with
white checkpoint-pixel assertions, keyboard CHANGE/KEEP dabs, explicit saved acknowledgment,
full-page read/write of the same draft, retained local CAS conflict and explicit reload, fixed
strategy checkpoint, Mock A/B/C, slider keyboard control, Ghost, issue confirmations, adoption,
Chinese layout and empty-boundary continuation. At 400 pixels they import three mismatched raw
fixtures, explicitly prepare Boundary Lock and retain a controlled human FAIL after adoption.

Synthetic File paste/drop events are tested at 360/400; this does not prove OS clipboard handoff.
HTML/URI events make no remote fetch, and invalid replacement MIME preserves the current edit.
Old/blocked backend UI states are exercised with controlled network responses at 480, and timeout
unit tests include a PNG body stream stalled after headers. At 360, a successful submit response
is deliberately lost; reload restores the server Run, and history contains one Run for the source.
The same isolated bundled-Chromium profile is closed/restarted and restores a paired acknowledged
continuation draft. Separate TestClient API restart tests recover both credential authority and draft.
At 480, a failed draft write followed by offline/online reconnect retains the local unacknowledged
input and disables edits while offline; restoring connectivity acknowledges the queued snapshot safely.

Download PNG magic and SHA-256 match the **adopted final asset**, including prepared imports.
Copy reports the real extension document API result; clipboard contents were not independently
pasted/read back. Copy-failure propagation is unit tested. These results are distinct from manual
Chrome/Edge copy and download acceptance, both NOT TESTED.
